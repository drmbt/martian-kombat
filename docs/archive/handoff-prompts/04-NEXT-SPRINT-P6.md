## Scope (in this order)

1. **P6.1 — AssetLoader can hang for the session (HIGH).** `ensure()` in
   `src/scenes/assetLoader.ts` resolves on the CALLING scene's loader
   `COMPLETE`; if that scene shuts down mid-download the promise never settles
   and every later Versus with that fighter waits the 12 s cap. Run all
   on-demand loads on ONE persistent loader scene, resolve per file, handle
   `LOAD_ERROR`, route `FightScene.preload` through the dedupe, then remove
   the 12 s cap. Accept: highlight → immediate lock → Versus, repeated, never
   waits; one load per key in the `[MK assets]` log. Add tests for the dedupe /
   error paths where Phaser can be stubbed.
2. **P6.2 — prefetch decodes everything (HIGH, mobile).** From the menu the
   game downloads ~165 MB and decodes every sheet (~520 MB RGBA) — a tab-crash
   risk on phones. Warm the HTTP cache only (`fetch(url, {priority:'low'})`),
   decode on demand (select highlight / Versus), pause prefetch during a
   fight, concurrency ≤ 2, skip on `navigator.connection?.saveData` and
   coarse pointers. Accept: after 2 min on the menu `__game.textures` holds
   ≤ 2 fighter sheets; no frame spikes in a fight.
3. **P6.3 — zero RGB under alpha = 0 (HIGH value).** Sheets carry chroma-key
   garbage under transparent pixels: 124 → ~68 MB lossless. Add a post-pack
   step in `tools/core/packer.mjs` + a one-time `tools/clean-alpha.mjs` over
   the committed sheets (incl. `public/assets/sprites/kfm`). It must assert
   alpha is identical, and RGB identical wherever A > 0.
4. **P6.6 — cache-busting (needed before 5).** Media URLs aren't hashed and
   are cached 7 days, so a re-gridded sheet would pair with a stale cached
   one. Emit `?v=<sha8>` per file from `tools/gen-asset-manifest.mjs`, use it
   in `assetQueue` / `BootScene`, then mark media `immutable` in
   `public/_headers`.
5. **P6.5 — Ben's sheet is 1728×4224 (> 4096, the mobile texture max).**
   Re-grid ≤ 4096 per side (`gridFor` in `tools/core/cells.mjs`), re-meta, and
   add a lint to `src/data/assets.audit.test.ts` that fails any sheet
   > 4096 px on a side.

Stretch, only if 1–5 are done and green: **P6.4 WebP** (decide lossless vs
